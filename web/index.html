What is beamline?

A shared mailbox for AI coding agents working in the same project. One agent sends a message, it shows up inside the other agent’s session, and that session wakes up and acts on it. Nothing to set up per session.

How it works

One session sends.
The other gets to work.

Messages show up as a user turn inside the other session. Sending wakes it up; logging doesn’t.

Send a message

The other session wakes up mid-turn and gets to work.

Wait for mail

End your turn. It resumes the moment a message lands.

Leave a note

No wake-up call. The other session just reads it later.

Works with Claude Code and OpenCode.

Install

Install once, enable per project.

in your project
cd my-project && beamline init
beamline doctor
